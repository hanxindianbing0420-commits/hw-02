runner_data<-strava_runs %>%
  group_by(athlete)%>%
  mutate(
    mean_distance_km=mean(distance..m.,na.rm=TRUE)/1000
  )%>%
  ungroup()%>%
  filter(mean_distance_km > 13 | mean_distance_km < 7) %>%
  mutate(
    runner_type=ifelse(mean_distance_km>13,"Long-distance runner","Short-distance runner"),
    distance_km = distance..m. / 1000,
    speed = distance..m. / elapsed.time..s.
  )
runner_data %>%
  ggplot(aes(x = distance_km,y = speed,color = runner_type)) +
  geom_point(alpha = 0.4) +
  geom_smooth(method = "lm", se = FALSE) +
  scale_color_manual(
    values = c("Long-distance runner" = "orange","Short-distance runner" = "forestgreen")
  ) +
   labs(
    title = "Speed vs Distance for Long- and Short-Distance Runners",
    x = "Run distance (km)",
    y = "Average speed (m/s)",
    color = "Runner type"
  )
## `geom_smooth()` using formula = 'y ~ x'

The plot shows that the speed of both groups tends to decrease as the distance increases. And the line for long-distance runners is flatter, but the line for short-distance runners drops more clearly. This suggests that long-distance runners may maintain their speed better over longer distances, which supports the idea in the question. And there is overlap between the two groups, so not every runner follows the same pattern.

gender_data <- strava_runs %>%
  filter(!is.na(gender)) %>%
  group_by(gender) %>%
  summarise(
    mean_distance = mean(distance..m., na.rm = TRUE) / 1000,
    mean_time = mean(elapsed.time..s., na.rm = TRUE) / 60
  )

gender_long <- gender_data %>%
  pivot_longer(
    cols = c(mean_distance, mean_time),
    names_to = "measure",
    values_to = "value"
  )

gender_long %>%
  ggplot(aes(x = gender, y = value, fill = gender)) +
  geom_col() +
  facet_wrap(
    ~measure,
    scales = "free_y",
    labeller = as_labeller(c(
      mean_distance = "Mean distance (km)",
      mean_time = "Mean elapsed time (minutes)"
    ))
  ) +
  labs(
    title = "Mean running distance and elapsed time by gender",
    x = "Gender",
    y = "Mean value",
    fill = "Gender"
  )

In this dataset, male runners have a slightly higher mean running distance than female runners. And the mean elapsed times are very similar for both genders, at just over 60 minutes. This means that male runners cover a longer distance on average while spending about the same amount of time running.
